# 二次元大肥鱼 sprites

- Original artwork created for this project with an AI image generator (2026-11), then cut out,
  composited (expression faces / blink & mouth patches on one shared body) and resized by script.
  It is not traced or copied from any existing illustration.
- "大肥鱼" is a community (fan-made) personification of DeepSeek. This character is an unofficial
  fan interpretation of that concept: it is **not** official DeepSeek art and is not endorsed by or
  affiliated with DeepSeek / 深度求索.
- Distributed with this app under the same terms as the app itself (GPL-3.0). The old procedural
  「简笔鱼」 avatar (DfyFish) is code-drawn and has no external assets.
