# 大肥鱼人生 · 第三方来源说明

Mibot 的「大肥鱼人生」模块是对社区项目 **dsh-dafeiyu-life**（大肥鱼 · DSH 生活系统）思路与部分逻辑的 Kotlin 原生移植：

- 上游：https://github.com/minedalang/dsh-dafeiyu-life
- 许可证：MIT — Copyright (c) 2026 c1overzz（上游根目录 LICENSE；上游 NOTICE.md 另列 adoresever/bilibili-mcp、Yuuyuko-uu/dsh-fish-memory 等来源）
- 移植内容：默认人设提示词（已改写以适配手机）、模拟情绪的八类心情/强度/18 小时半衰期与效果表、兴趣阶段规则（短期/成长/稳定/淡出）与主题识别表、经历记忆 clear→fuzzy→trace→forgotten 的衰减公式、反思产出“认识 + 行为”的质量要求。
- 这是独立实现，并非上游作者或 DeepSeek、哔哩哔哩官方产品；“大肥鱼”是 DeepSeek 蓝鲸的社区同人形象。
